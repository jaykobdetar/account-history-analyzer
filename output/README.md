# Saved report examples

These are preserved outputs from artificial data. Use fresh `my-report*` directories for your own runs, following the [usage guide](../docs/USAGE.md).

| Example | What to inspect |
| --- | --- |
| [Arithmetic report](rw001/arithmetic-source/report.md) | Small complete pipeline example with insufficient-data statuses; [HTML](rw001/arithmetic-source/report.html) can be opened locally |
| [Alternative-only sensitivity candidates](rw001/synthetic/alternative_only/report.md) | Stored alternative settings can contain candidates even when the primary set is empty |
| [Matched plus extra candidates](rw001/synthetic/matched_plus_extra/report.md) | Matched and additional sensitivity candidates |

The [synthetic presentation record](rw001/synthetic/README.md) explains how the two sensitivity examples were constructed. They are renderer regression demonstrations. They must not be interpreted as measured account-switch detection results. The arithmetic bundle and synthetic presentation bundles have different recorded scopes; consult their receipts before attempting replay.

Older sample bundles remain in the [frozen release archive](https://github.com/jaykobdetar/account-history-analyzer/releases/tag/v1.0.4). Real-text study artifacts containing original prose remain private; the [study catalog](../studies/README.md) links public aggregate results.
