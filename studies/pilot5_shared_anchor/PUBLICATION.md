# Public evidence and private inputs

This append contains the completed exploratory results, method and execution registrations, sample summaries, evaluation code, tests and actual receipts. Original source writing, source-account/record maps, input snapshots and complete analyzer reports remain private. Source-dependent reproduction requires separately authorized access to these artifacts.

`PUBLIC_EXPORT_MANIFEST.json` maps original local SHA-256 values to published SHA-256 values. Executable Python files are copied byte-for-byte. Non-code copies may replace host-specific paths with descriptive placeholders. Original frozen hashes inside receipts remain unchanged; when a copy was transformed, reconcile its binding through the manifest's original hash. This publication step does not amend executed code or evidence.

The public result JSON retains candidate and legal-grid positions, volume, timestamps, module availability and resource counts. It excludes source IDs and prose. Hashes do not make private text recoverable or anonymous. Privacy checks are bounded mechanical checks against known identifiers and source-text sequences, with their limitations recorded.

Pilot4, earlier studies and the production analyzer are preserved. The Pilot5 output is a single nonreciprocal shared-anchor diagnostic, not a population-accuracy estimate.
