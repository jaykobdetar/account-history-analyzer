# Evaluation studies

AHAS has five preserved local studies. They answer different questions and retain their original protocols, outcomes, failures and limitations. The current analyzer is frozen at **1.0.4**; Pilot 1 used 1.0.3. Real-world authorship or takeover validity is **not established**, and the protected confirmation reserve remains unscored.

| --- | --- | --- | --- |

Already inspected development evidence, not an untouched confirmation study. Its report-visibility defect was later repaired in 1.0.4. | [Study overview](pilot1/historical-1.0.3/README.md) · [Public review](pilot1/historical-1.0.3/review/PUBLIC_REVIEW.md) |

For the latest executed chronological example, start with **Pilot 5**. For the larger cross-community comparison study, start with **Pilot 3**. Pilot 4's feasibility stop remains a separate result; Pilot 5 does not replace it or retroactively satisfy its stricter design.

## How to read these records

- Source-account labels are dataset proxies, not verified human identities. A candidate near a constructed switch does not establish detection of a real takeover.
- Keep planned, executed and qualified counts separate. An unavailable result is not a zero; repeated pairs, arms and shared source samples are not independent subjects.
- Each study's final review is the interpretation entry point. Protocols, drafts, amendments, original receipts and earlier failures remain historical evidence at their existing paths.

## Public artifacts and reproduction

The study directories contain sanitized protocols, aggregate results, evaluation code and verification evidence. Raw corpora, original writing, private exports, source-account maps, prepared real-text inputs and unredacted analyzer outputs remain outside the repository. Exact source-dependent replay requires the authorized private artifacts and their bound identities; a Git clone alone does not supply them. Historical local paths and hashes document the actual runs.

The generic software and synthetic examples are independently runnable: see [usage](../docs/USAGE.md) and [development checks](../docs/DEVELOPMENT.md). Original frozen software and review bundles are available from the [1.0.4 release downloads](https://github.com/jaykobdetar/account-history-analyzer/releases/tag/v1.0.4). Later study publication notes/manifests explain their own sanitized exports; they are not relabeled as contents of the earlier release.
