# Public package and original evidence

This package contains aggregate study evidence and evaluation-only code. Private source archives, original prose, account/record/thread maps, candidate pools, audit provenance and prepared private artifacts are excluded. The final cohort is empty; no empirical chronological result files or replay outputs exist.

`PUBLIC_EXPORT_MANIFEST.json` maps each original local artifact's SHA-256 to the published copy's SHA-256. Executable Python source is copied byte-for-byte. In non-code publication copies, host-specific working directories may be replaced with descriptive path placeholders. Original frozen hashes inside receipts remain unchanged, so a binding to an original file must be checked against the manifest's original hash when the public copy was transformed. Path replacement is a publication operation, not an amendment to the executed methods or evidence.

The source-dependent steps require separately authorized private inputs. The published hashes establish artifact identity; they do not recover or anonymize source writing. Source accounts are unverified identity proxies. `drafts/` contains explicitly unvalidated, unexecuted work and must not be treated as successful verification.

Earlier studies and the production analyzer are outside this append-only publication. The study's preparation deficit, unsuccessful attempts, corrected evaluation checks and unmeasured analytical outcomes are retained.
