# AHAS V1 limitations

`real_world_validation: not_established`

AHAS is an offline descriptive measurement instrument. Engineering completion, numerical correctness, synthetic behavior and scientific validation are separate. Consult `EVALUATION.md` for commands actually run, results, failures and skipped checks. A registry entry or implemented function is not evidence that an acceptance test or external evaluation passed.

## Interpretation

- A measured pattern does not prove its cause. Style distances are not authorship probabilities or identity evidence; a zero distance establishes equality only of that representation.
- Candidate boundaries minimize a specified penalized objective. They are not statistically significant author changes, exact takeover times, or calibrated alerts. Parameters and minimum-size guards are unvalidated engineering settings.
- Sensitivity matching describes stability under executed settings. It is not confidence, and related feature families are not independent witnesses.
- Content matches establish shared wording under named rules. They do not prove deceptive intent, automation, ownership, plagiarism, or contextual originality. A connected reuse group is not a set of pairwise equivalent records.
- Timestamp gaps are not sleep or verified inactivity. Creation-to-parent-creation delay is neither typing time nor read-to-reply time. Missing parents are missing context.
- Link repetition is an observable hostname count. It does not establish advertising, payment, sponsorship or intent. Community metadata does not establish topic, nationality, political identity or real-world location.
- AI-text detection is `not_implemented_in_v1`. The suite produces no bot/human probability, AI percentage, deception score, medical/mental-state inference, authorship verdict, or sensitive-trait classification.

## Supplied data and text views

Provenance, language, coverage, timestamps and editing information are supplier declarations. No records are fetched or independently verified. Even `complete_for_declared_scope` is a declared scope. Hashes prove correspondence with bytes, not their truthfulness, authenticity, authorship or completeness. Missing or insufficient data stays missing; a zero count requires an observable denominator/scope.

Observed text is ordered by supplied creation time. An edited record's current text is not necessarily what existed at creation. Known edits remain visible in primary analysis with an exclusion sensitivity when enough data exists; unknown edit state is not evidence of no editing. Collection gaps and missing times limit temporal interpretation. Equal timestamps have no established sub-resolution event order.

The pinned CommonMark parser is not Reddit's full Markdown dialect. Explicit blockquotes/code/HTML/image tokens can be excluded, but ordinary quotation marks and semantic quotation/copying cannot be inferred. Removing HTML tags does not verify authorship of surrounding text. The conservative HTTP(S) scanner may leave unknown address formats in text. Descriptive link labels can contain topical wording.

NFC and the operational lexical regex are documented transformations, not linguistic correction. Hyphens and underscores split words; contractions stay one token; Unicode categories need not align with every language's word/numeral conventions. Character counts and alphabetic word length count Unicode code points rather than grapheme clusters. No spelling correction, semantic interpretation, trusted sentence segmentation or readability assessment is supplied.

Function-word and masked comparisons require declared English. The curated vocabulary and literal contraction pairs are engineering resources, not validated individual fingerprints. String alternatives are not proven interchangeable in context. Masking preserves lengths, punctuation and some vocabulary and is not provably topic-free. Generic text/reuse/activity analyses remain possible for other/unknown declared languages.

## Sampling and numerical scope

Whole-record windows vary in actual word count. Record-count guards do not ensure independence; a single long record can dominate. Community-controlled comparisons are only partial context controls. Changes in community mix, lengths and missingness can accompany measured writing changes.

Character n-gram profiles are overlapping and correlated. Raw and masked distances use different representations and cannot be interpreted as interchangeable probabilities. Delta requires a suitable external frozen reference with compatible units/provenance; no research reference corpus is bundled. The toy reference is arithmetic-only and must be visibly labeled when explicitly enabled.

Temporal population scaling uses the supplied stream. Adding history can alter standardization and boundaries. Family weights, penalties, window lengths and matching tolerances are experimental defaults. Exhaustive small-sequence agreement tests optimizer correctness, not calibration for real accounts.

Exact shingle search preserves set equality but has finite candidate, posting, work-reservation and evidence budgets. General longest-passage matching uses an exact segmented suffix automaton; logical work units are not CPU seconds or a universal memory bound. A resource-limited near-reuse result is incomplete, even if exact duplicate analysis completed. Shared five-token shingles do not establish a single contiguous passage. Exact repeat reduction and optional greedy near reduction are content-deweighting experiments and can remove relevant recurring wording.

## Evaluation, reproducibility, and privacy

Shipped texts are overtly synthetic software inputs. Their sidecars describe construction operations; they do not label real authors, bots, AI text or takeovers. Changing construction labels must not change analytical results. No source paper's reported accuracy transfers to this pipeline. Missing external datasets/labels yield `not_evaluated`, not invented scores.

Pairwise external text tasks and full chronological stream tasks answer different questions. Related authors, documents, threads and near-duplicate groups need separation when metadata exists; missing grouping information prevents a verified leakage-free claim. PAN sentence/document labels cannot be repackaged as real account timestamps or bot/AI ground truth. Descriptive metrics do not manufacture independent observations or confidence intervals from correlated pairs.

Canonical byte identity applies only to environments actually tested. A reference-container recipe is a reproduction route, not proof it was built or tested. Numerical-library, Python/Unicode and rendering changes may affect outputs; thresholds must not be rounded to conceal differences. Operational receipts intentionally differ across runs and remain outside canonical measurement identity.

Reports and evidence may contain sensitive original prose, source IDs, timestamps and context. Pseudonyms and hashes do not anonymize content. Rendering with excerpts omitted reduces display of prose but does not make remaining results anonymous; analytical artifacts may still contain source text. Source strings and links are untrusted, and static reports must escape them and use no remote assets or telemetry.

Generated-artifact limits are separate from the 50 MiB source limit:256 MiB per file,512 MiB per published bundle,32 files and 1 MiB config/checksum metadata. Configuration may tighten these ceilings. Oversized publication is refused atomically without truncating contributions/evidence. JSON parsing remains memory-resident within the file limit. `verify --recompute` regenerates every canonical artifact; integrity-only checks cannot establish authenticity if data and corresponding hashes were both replaced.
