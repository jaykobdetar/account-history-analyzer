# Decisions

1. The supplied input schemas remain the external contracts. Manifest default_language is required; use the explicit value `und` when unknown. Record null language inherits it. We do not guess language.
2. Implementation uses compact modules with immutable snapshots/configuration and fresh analytical outputs. CLI and renderer remain separate from computations.
3. Bundled defaults/resources/schemas are installed package data. No current-directory assumptions. External Delta paths resolve relative to the supplied config file; analytical identity uses their byte digest and reference ID. No reference is fitted by the analyzer.
4. Source-tree fingerprint covers installed Python, resources and contracts, excluding caches. Results contain a stable numerical-environment identifier; actual hardware, duration and file paths go in receipts.
5. Input timestamps retain their supplied representation in canonical snapshots, with integer UTC microseconds for ordering/calculation. Equivalent spellings of timestamps are not promised the same snapshot hash (only input key/row/whitespace permutations are).
6. No license was selected by the owner. The release includes a LICENSE notice reserving ownership rather than inventing a project license; dependency license notices are audited separately.
7. Network namespaces are unavailable in this host (`unshare -n` returned Operation not permitted). Offline executions will use an inherited Linux seccomp syscall filter, verified by an attempted socket operation, and record that actual isolation method.
8. The input byte budget covers manifest plus JSONL. Capture-relative future dates and supplied parent cycles are warnings; inconsistent timestamps for an internal parent are errors. Cycles are detected iteratively. No check depends on today's date.
9. Markdown URLs are protected before parsing so emphasis inside a bare URL cannot leak URL fragments into style. Placeholders are collision-free for the supplied normalized source, restored before extraction, and do not change source line maps. One hyperlink destination is one occurrence, including autolinks or URL-only labels; a URL printed as a hyperlink label is not also counted as an independent bare link.
10. `paragraphs` counts retained prose blocks (including headings/list items); `segments` additionally counts hard boundaries introduced by exclusions. The distinction is exported rather than silently treating every segment as an original paragraph.
11. Pooled function-word frequencies use only usable declared-English word tokens; `english_word_count` exposes that denominator separately from all-language direct counts.
12. Manual selection identity is expanded and included as `manual_selection` in the resolved analytical config for comparison runs. It is separate from TOML input settings. ID lists are sorted because selectors are sets; overlaps require an explicit diagnostic override.
13. The frozen reference is read once, parsed and hashed from the same byte buffer, and copied to delta_reference.json when supplied. Sensitivity config overrides retain that in-memory resource. Reports mark toy_reference even when no qualified comparisons exist.
14. Classical Delta uses the algebraically identical `abs(fA-fB)/sigma` per coordinate to avoid catastrophic cancellation from subtracting two large standardized values. Reference means remain mandatory and validated; this is a numerical stabilization of the specified formula, not a different Delta variant.
15. Human-facing reuse/comparison previews show at most20 groups/pairs/comparisons. Omitted counts and complete artifact locations are explicit. This is a fixed template presentation limit, never an analytical search cap.
16. Historical 1.0.0 decision (superseded for optimizer implementation by the PR #383 decision below). A concrete pinned ruptures1.1.10 PELT counterexample violates the specified minimum-size-constrained optimum: raw scalar [0,9,2,8,3,0,10], min_size3, penalty0.1. It returns internal boundary4/objective111.51666666666667, whereas legal boundary3 costs107.51666666666667. Production uses a named delayed-pruning PELT control-flow adaptation with the pinned CostL2 primitive: a dominance witness at t can expire a candidate only at t+min_size, when the replacement segment becomes legal. Conservative floating-point pruning slack keeps uncertain ties; objective values are not rounded. The corrected objective must pass independent exhaustive/DP tests before the M4 gate. The installed library is not represented as correct on that counterexample.
17. The V1 segmentation product guard is at least8 qualified windows; configs requesting a smaller minimum are rejected explicitly. Low-level numerical helper tests operate below this product guard without redefining the product method.
18. Complete UTC daily-bin expansion has an explicit `activity.max_calendar_days = 366000` resource bound. Two small records may otherwise request millions of days (years0001–9999). Exceeding the bound is a resource-limit error before allocating the calendar table; no dates are silently truncated. This is a resource bound, not a claim about expected account lifespans.
19. Sensitivity alternatives vary one construction at a time over pooled streams. Primary community streams provide the community control; no target×community×exclusion Cartesian expansion is performed. Constants count as executed measurements; insufficient streams do not. Cross-construction boundary intervals are open between records: endpoint touching is reported separately from interior overlap.

## Output directory resolution

Artifact publication rejects symlinks in the output path, resolves lexical `..`, and refuses the current working directory or any ancestor before staging. This closes an overwrite path that could otherwise replace the project directory through `../subdir/..`. Dedicated output directories remain atomically replaceable with explicit `--overwrite`. Regression tests exercise lexical traversal and symlink ancestors.

## Required report artifacts and optional heatmaps

V1 analysis always writes the required JSON, Markdown and HTML artifacts. `report.formats` therefore accepts only the complete default list; `ahas render --format` selects derivative presentations. The supplied `style.max_all_pairs_windows` field is retained as the cap for optional all-pair heatmaps. This release computes required adjacent/manual/sensitivity comparisons and does not implement optional heatmaps.

## Four audit repairs (1.0.2)

The user's subsequent direct instruction, “Focus on the four audit findings from the attachment now,” authorizes AHAS-AUD-001–004. The previous PR-only scope is historical. Preserve that exact optimizer backport and its immutable source/commit/license. New receipts and fixture reports use `audit-repair` directories. The source archive from 1.0.1 and an installed copy provide the baseline; this supplied directory has no Git repository.

The 50 MiB source-input limit remains independent of generated artifacts. Choose a release artifact envelope of 256 MiB per file, 512 MiB across the published bundle (including checksum manifest and operational receipts), and 32 files. `checksums.json` and `resolved_config.json` additionally have a 1 MiB metadata ceiling. Configuration may tighten these ceilings but cannot raise them. This admits the reproduced 92,001,915-byte default benchmark result without changing analytical thresholds, contributions, or evidence. It is a bounded supported envelope, not a guarantee for every input permitted by the source limits or a universal RAM/runtime bound. Unknown extra files added to a directory after publication are outside its checksummed bundle.

Canonical JSON serialization and hashing emit bounded chunks; readers stat-check first and use bounded reads. JSON still parses into memory within its file ceiling. Publication charges bytes while writing a staging directory and refuses overflow atomically, retaining an existing output on failure. No success directory is published with truncated evidence. Generic `load_json` keeps its source limit. Resource failures remain explicit exit4.

`verify --recompute` regenerates **every canonical artifact**, including Markdown, HTML, charts and checksum manifest. Operational receipts are excluded. Integrity-only verification proves agreement between supplied hashes and bytes, not authenticity; replacing an artifact and its checksum can pass integrity-only verification but must fail full replay. Canonical configuration controls original report excerpt mode; receipt edits cannot change replay behavior. A derivative `render --excerpts none` is a presentation export, not a replacement analysis bundle.

Map order is explicit: statuses use their fixed semantic order; punctuation, contractions and nested structured map values use sorted keys. Ordered lists and chronology remain ordered lists. Renderers support immutable analysis mappings directly and the equivalent parsed canonical JSON without whole-result copying.

Near-reuse matching uses exact token equality with a segmented suffix automaton and the original longest-match/segment/offset tie rules. It does not suppress frequent tokens. Resource budgets count deterministic reservations, including repeated posting visits, conservative sort/membership work and evidence materialization. Any exhausted near phase withholds all near pairs, groups and reductions; exact groups remain complete. Candidate counts are marked lower bounds only while enumeration was incomplete. Choose 250,000,000 default work units after measuring 209,265,929 pre-matching reservations for the declared 1,000-record benchmark; retain two million candidate pairs, two million index postings, two million evidence tokens and eight million evidence code points. This is capacity calibration, not statistical threshold fitting. The scientific thresholds and benchmark inputs are unchanged. Detailed charging rules and observed growth are in `REUSE_RESOURCE_POLICY.md`.

A hyperlink contributes its destination once. HTTP(S) text inside its visible label is an excluded span and creates a hard text boundary, even when the label also contains descriptive wording, emphasis or code. A different hostname printed in a label is not a separately navigable link. Separate hyperlinks with the same destination remain separate occurrences. No global URL deduplication is introduced.

Suite, registry and template versions become 1.0.2; affected text/link/reuse methods are versioned accordingly. The optimizer remains method version 1.0.1. Result format 1.0.0 is retained with a strict version-gated reuse extension; archived payloads remain readable, and current results require resource counters, limits and exhaustion reason. The new fingerprint means old analyses must be replayed with their archived implementation, not silently accepted as current output.
