## Presentation contract

The overview in `src/account_history_analyzer/reporting.py:render_markdown` traverses `style.streams` in exported list order, then `sensitivity.penalty_settings` in predefined list order. It joins stored change results and matching rows by stream/setting identifiers. Mapping insertion order has no meaning. The renderer does not call feature extraction, matching or optimization.

Candidate count is the number of exported boundary objects. Primary-matched count is the number of stored one-to-one matching pairs. Unmatched-setting candidate count is the number of stored unmatched setting boundary indices. An executed `ok` or `no_measurable_variation` result can have zero candidates. A skipped/insufficient result shows unavailable counts; an executed setting with an unavailable primary shows not-comparable matching counts. Disabled alternative constructions retain their separate `not_run` status and `disabled_by_configuration` reason without inventing a new penalty-result enum.

Each setting with candidates has a disclosure containing the stored original-record interval, source endpoint IDs, endpoint times and full adjacent window times. These intervals do not identify an exact event date, author change, significance or confidence. Existing primary matching details remain visible. Anchors combine the setting, stream and boundary IDs through a digest; source values use the existing inert text escaping. These details add no source prose excerpts. Both excerpt modes preserve the established n-gram disclosure rule and lossless label notation.

RW-002 receives a small terminology clarification: the existing `unsafe_scheme` parser category includes unsupported/scheme-less destinations and does not establish maliciousness. RW-003 remains an explicit scope limit: body/title text does not include native post destination metadata outside the input contract. Neither the parser nor input model changes. RW-004 runtime/memory/output cost, stable-zero feature presentation and a shorter overview remain separate work.
