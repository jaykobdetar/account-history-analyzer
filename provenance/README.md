- [Original specification handoff](../docs/archive/original-handoff/README.md) preserves the pre-implementation documents.

Use the [study catalog](../studies/README.md) for experiment evidence and the [documentation index](../docs/DOCUMENTATION_INDEX.md) for the current reading order. None of these historical receipts constitutes a fresh test of later repository edits.
